# 个人 QD 观察台

基于参考页面重新设计的本地网页。保留基金搜索、自选、申购限额、估值、历史表现、跨境 ETF 与全球行情功能，采用极简数据画布界面，适合桌面和手机使用。

## 个人访问入口

地址：https://hurrypage.github.io/qd-personal-studio/

访问密码：`1234`。进入状态保存在当前标签页的 sessionStorage，刷新可以继续使用；点击“锁定页面”重新要求密码。电脑与手机均可使用。

这是浏览器端的简单访问入口，不是安全认证。仓库、页面文件和密码校验逻辑均公开，无法保护敏感信息。原来的 `qd-fund-studio` 页面保持独立。

## 运行

在此目录运行：

```powershell
python -m http.server 8878 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8878/`。页面无需安装前端依赖。如果该端口已被占用，可以换用其他空闲端口。

## 数据说明

基金与市场数据由浏览器直接读取天天基金、腾讯行情和 CNBC 的公开接口。今年涨幅与历史净值使用天天基金公开净值序列计算，基准为上一年最后一个净值日的累计净值；基金未成立或缺少基准净值时显示缺失，不补零。预置持仓继承自参考页面。申购额度优先采用可解析的基金公告快照（`limits.json`），其余份额尝试读取天天基金申购接口；旧预置金额和无法可靠解析的最新公告显示“待核验”，不当作当前限额。公告链接与日期显示在基金卡片上。GitHub Actions 每 6 小时检查一次公告，但源站可能延迟或不可用，购买前仍请核对基金公司公告。自选、排序、基金列表和估值快照仅保存在当前浏览器。估值仅供参考。

基金搜索框会即时筛选当前列表，同时查询可添加的基金。添加或查看已有基金后会收起搜索结果并定位到对应基金；按 Esc 可清空搜索。

重点基金图和每只基金详情图增加同期沪深 300 对比。指数日线取自腾讯公开接口；两条线使用同一组基金净值日期，以最近一个不晚于该日期的指数收盘价对齐，并分别从共同起点归一为 0%。图中的百分比是所选区间收益率，基金原始累计净值仍单独显示。指数历史行情不可用时明确显示缺失，不生成示意曲线。

跨境 ETF 列表可按需展开场内收盘价与沪深 300 的同期走势图，支持近一月、近三月、近一年、近三年切换；日线来自腾讯公开接口，按交易日期对齐。全球行情页的 QDII 限额速览仅展示公告核实或申购接口核对过的单日上限，标明来源与日期；最新公告尚无法解析的基金列为待核验。金额是申购上限，并非实时剩余可买额度。

电脑端展开基金后，左侧展示净值走势与历史表现，右侧直接展示持仓；较窄屏幕恢复纵向排列。

手机端展开基金时，先显示走势和前五项持仓，其余已展示持仓可按需展开（最多前二十项）；阶段表现压缩为两行，时间区间可横向滑动。没有估值快照时不显示空的历史估值模块。

`app.js` 保留参考页面的数据与计算逻辑，`ui.js` 调整筛选和页面交互，`styles.css` 与 `index.html` 为重新设计的界面。该项目与旁边的财务台账相互独立。

## 我的个人持仓

全球行情页顶部按截图列出 21 只基金，A/C 份额独立使用对应净值。支持搜索、按实时估算或今年至今收益排序、查看公开持仓，以及切换区间比较沪深 300。未录入金额或份额，不计算个人盈亏。移出个人清单不删除基金总览中的基金，支持恢复截图清单。

个人版采用独立的本地存储名称，首次使用可复制旧版基金自选，不影响原站之后的列表。`personal-funds.json` 保存代码清单，`scripts/update_personal.py` 从天天基金公开档案获取名称、份额净值及公开股票/债券持仓，快照保存在 `personal-data.js`。工作流每 6 小时检查数据，浏览器继续补拉净值和行情。持仓日期反映披露期，不能视为当前完整持仓；部分 ETF 联接基金没有近期股票明细，指数代理估算明确标注，债券基金没有可靠实时估值时显示缺失。

持仓基金名称、快照和页面内容均在公开仓库中，简单访问密码无法保障隐私。
